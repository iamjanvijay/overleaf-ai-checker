# Privacy Policy — Overleaf AI Checker

Overleaf AI Checker runs only on https://www.overleaf.com/project/* pages.

- **What it reads:** the text of the pages you select from the PDF you compiled in your own Overleaf project, when you click "Download highlighted PDF".
- **Where it goes:** that text is sent to Pangram (text.external-api.pangram.com) with the API key you entered,
  to obtain AI-likelihood scores. It is not sent anywhere else.
- **What is stored:** your Pangram API key, in Chrome's extension storage (synced with your
  Chrome profile if sync is on). Scores are kept in memory only while the browser session lasts.
- **No tracking:** no analytics, no cookies, no identifiers are collected by the extension.
- **Removal:** uninstalling the extension deletes the stored key.
